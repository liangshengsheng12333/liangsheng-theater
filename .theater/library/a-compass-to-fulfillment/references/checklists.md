# 阿米巴经营哲学落地执行检查清单库 (Amoeba Checklists)

> **归属法典**：《活法》与阿米巴经营哲学 (A Compass to Fulfillment & Amoeba Management)  
> **核心定位**：将宏大的心智哲学转化为可在制造车间、销售前端、采购后方逐项打勾的可执行标准。

---

## 一、阿米巴组织划分实战核对表 (Amoeba Division Checklist)

- [ ] **核算独立性检查**：该单元是否具备清晰可计量的独立输入（物料、半成品、工时）与独立输出（成品、交付成果、客户货款）？
- [ ] **人员规模适度性**：该阿米巴单元人数是否控制在 5~15 人以内？（若超过 20 人，阿米巴长无法洞悉每个成员的精进状态，必须二次切分）；
- [ ] **职能闭环性**：该单元能否独立为最终交付结果承担完整质量与工期责任，杜绝“负责做但不负责修”的脱节；
- [ ] **干部人选匹配性**：选任的阿米巴长是否具备“自燃型”特质，是否认同“作为人，何谓正确”的利他哲学；
- [ ] **反本位主义防线**：划分后是否制定了跨阿米巴支援的协同积分机制，严防各单元自立山头、各自为政。

---

## 二、单位时间核算表 (Hourly Value-Added Sheet) 推行核对表

- [ ] **日清日结机制**：是否建立起“今日核算、今日录入、次日晨会公布”的高频反馈闭环？（月度核算无法刺激神经，必须精确到天）；
- [ ] **总工时全口径录入**：阿米巴全员投入总工时是否严密涵盖了：
  - [ ] 正常法定出勤工时；
  - [ ] 全部加班工时；
  - [ ] 间接借调与兼员工时；
- [ ] **直接费用抠唆审计**：各项直接开支是否按阿米巴明细归集：
  - [ ] 电费、水费、压缩空气能耗；
  - [ ] 易耗品、刀具磨损、润滑油与劳保用品；
  - [ ] 厂内运输与装卸费；
  - [ ] 办公耗材与差旅费；
- [ ] **附加价值真实性审计**：附加价值计算公式是否严格执行：
  $$\text{附加价值} = \text{生产总额} - (\text{外部采购} + \text{内部采购} + \text{一切直接费用})$$
  严禁将未出货的残次品、呆滞品虚增为生产总额。

---

## 三、经营原点与动机至善自省清单 (Motive & Origin Checklist)

- [ ] **名分大义检查**：当前企业推进的战略动作，其公开宣称的目的究竟是为了“创始人发财”还是为了“全体员工幸福与客户托付”？
- [ ] **定价定天下检查**：当面对大客户压价时，最高统帅是否亲自介入测算，寻找“客户感到超值、我方保留合理尊严与利润”的奇点？
- [ ] **反贪婪陷阱检查**：
  - [ ] 是否存在为了眼前的蝇头小利而偷工减料、弄虚作假的行为？
  - [ ] 是否存在靠拉长供应商账期、恶意克扣上游货款粉饰经营性现金流的恶劣行为？
  - [ ] 是否在报表上隐匿了不良债权与报废存货？
- [ ] **空巴（哲学交流会）机制**：领导层是否每月至少召开两次不拘形式、敞开心扉的哲学酒话会，与阿米巴长坦诚沟通企业大义与人生意义？

## 四、阿米巴内部买卖定价结算规程 (Internal Market Trading Rules)

| 交易环节 | 结算基准原则 | 争议裁决协议 | 严禁行为 |
| :--- | :--- | :--- | :--- |
| **采购阿米巴 $\rightarrow$ 生产阿米巴** | 按照外部公允市场采购价 + 约定管理服务费（通常 3%~5%）结算 | 若生产部发现外部有更低价且保质的渠道，采购部须在 3 天内跟进或允许生产部直采 | 严禁采购部吃拿卡要与强行摊派高价不良物料 |
| **注塑/零件阿米巴 $\rightarrow$ 总装阿米巴** | 市价倒推法：根据终端售价倒推总装与各零部件的附加价值贡献率 | 总装阿米巴对外观瑕疵及尺寸公差拥有一票否决拒收权，返工工时全部由上游承担 | 严禁上游阿米巴强行将未检验合格品向下游移交 |
| **总装制造阿米巴 $\rightarrow$ 跨境电商/销售阿米巴** | 制造公允成本 + 制造目标利润（锁定制造端合理附加值） | 销售阿米巴不得单方面压低内部买入价，外部若降价，需由经营统括会联合裁决 | 严禁销售部门私自以降价促销甩包袱给工厂 |
