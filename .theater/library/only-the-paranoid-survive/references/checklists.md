## 1. 战略转折点 (SIP) 信号与噪声过滤清单 (Signal vs. Noise Filter)

在遭遇市场震荡时，必须使用本清单过滤虚假噪音，确认是否面临真正的 10X 战略转折点：

### 维度一：外部力量 10X 突变判定 (10X Force Verification)
- [ ] **价格与成本维度**：外部竞争对手是否以原先行业成本的 $1/3$ 甚至更低价格发起倾销？如果是，打勾（确认 10X 威胁）。
- [ ] **技术与替代品维度**：是否出现了直接绕过你核心功能的基础设施级替代方案？客户是否正在用新方案自建？如果是，打勾。
- [ ] **客户行为偏离度**：在最近 90 天内，核心大客户是否有超过 20% 的流失，且流失原因并非服务态度，而是采购逻辑发生不可逆重构？如果是，打勾。
- [ ] **互补品叛变度**：原本依赖你的生态伙伴是否正在将你的产品降级为一个可被任意替换的边缘插件？如果是，打勾。

> 判定准则：若上述 4 项中有 2 项及以上打勾，系统**已正式步入战略转折点**。

## 2. 战略失谐度 (Strategic Dissonance) 审计清单

用于诊断组织内部是否存在“言行不一、两头撕裂”的致命病灶：

- [ ] **工时与研发去向审计**：
  - 核心架构师与高级开发人员在过去 60 天内，是否有超过 50% 的时间在给濒死的旧业务/非标定制打补丁？
  - *若有，属于典型战略失谐，立即红灯。*
- [ ] **现金流净流向审计**：
  - 账面剩余现金是否依然在为毛利为负或账期超过 120 天的定制项目垫资？
  - *若有，属于严重战略失谐，立即切断资金供给。*
- [ ] **销售奖励政策对齐审计**：
  - 销售团队是否依然可以通过签下高定制、低毛利、拖死研发的单子拿到提成？
  - *若有，属于制度性失谐，24 小时内作废旧提成方案。*
- [ ] **管理层言行一致性比对**：
  - 管理层在公开会议上所说的“战略重心”，与下个月财务预算表中的最大支出项是否指向同一个目标？
  - *若不一致，判定战略失谐，暂停所有非核心项目立项。*

## 4. 战时建设性冲突 (Constructive Confrontation) 质询模版

在召开闭门路线决断会议时，主持人强制要求 CTO 与业务负责人回答以下对决问题：

1. **致 CTO 的质询**：
   - “你主张全员押注 AI Agent，请拿出证据：在过去 30 天里，有多少真实客户愿意为你设想的 Agent 原型支付真金白银？在巨头也在做 Agent 的情况下，你的壁垒是代码行数，还是具体的业务上下文数据？如果 3 个月内做不出爆款，你的技术构想能直接给团队发工资吗？”
2. **致业务 VP 的质询**：
   - “你主张继续接传统大客户私有化定制，请拿出数据：过去做过的定制项目，毛利率扣除研发人员工时后到底是正还是负？定制客户在一年后的复购率是多少？客户流失 30% 是因为我们定制不够努力，还是因为大厂的标准品用 $1/5$ 的价格直接满足了他们 80% 的需求？你还要把团队往泥潭里拖多久？”
