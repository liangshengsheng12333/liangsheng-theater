# ADR 0004: 双模唤醒机制、人设锚定防线与谢幕签署协议

## 状态
已采纳 (Accepted) - 2026-10-09

## 背景与上下文
在完成窗口物理调度与蒸馏资产规划后，需要确立：
1. 如何在不生硬、不出戏的前提下触发剧院总导演；
2. 长文本实战交付物输出时，如何避免大模型产生 AI 公文味导致人设崩塌；
3. 最终演训如何达成标准化的完工签署。

## 决策

1. **双模唤醒协议 (Dual-Mode Awakening Protocol)**：
   - 自然语言仪式短语（“有请凉笙歌剧院” / “今晚歌剧院开戏” / “启幕”）作为第一公民，赋予总导演钟鸣入场的高代入感仪式；
   - 快捷命令（`/curtain-up`, `/opera`）作为等价暗号；
   - 杜绝枯燥冰冷的脚本感。
2. **联合人设防线 (Voice-DNA Anchor & Reflection)**：
   - 交付物按章节嵌入第一人称决策叙事与主角标志性警句；
   - 全文严禁出现“作为一个AI语言模型”等破坏沉浸感的句式；
   - 成果文档末尾附带主角第一人称手签寄语与防伪认知水印。
3. **成果固化为谢幕档案 (Curtain Call Dossier)**：
   - 最终交付成果以统一 Markdown 格式存入 `.theater/sessions/<session_id>/CURTAIN_CALL_DOSSIER.md`。

## 影响与后果
- **正面影响**：确保了全流程极致的艺术沉浸感与工程落地的严肃性并存。
