01 凉笙歌剧院是什么？它根治了什么痛点？

很多朋友都曾尝试过让 AI 扮演“马斯克”、“芒格”或“战略顾问”来帮自己分析业务或解答困惑，但往往聊上两三句就深感失望：

❌ 痛点 1：浮于表面嘴炮

传统扮演只会模仿几句名人口癖。面对真实的财务血拼、代码架构或团队内耗时，拿不出任何成体系的硬核方法论。

❌ 痛点 2：长文人设崩塌

一旦要求写出切实可行的战略总案，AI 立即退化为毫无棱角的“公文生成器”（开口闭口“首先、其次、作为一个AI”）。

❌ 痛点 3：缺乏方法论工具

没有将大师个人的直觉心智模型与经典专著的实战检查清单缝合，给出的建议无法落地打勾执行。

凉笙歌剧院正是为了终结上述顽疾而生的工业级智能系统。它开创性地将人类顶级智囊的心智操作系统与经典法典的可执行工具箱深度熔炼，通过严格的三幕式流程，为你打造当期专属的铁血实战智囊。

02 两大底层技术支柱：女娲范式 + 仓颉范式

🧬 女娲体系 (Nuwa Skill) —— 萃取大师灵魂

“蒸馏任何人的思维方式 —— 心智模型、决策启发式、表达DNA。”

  • 六维深度调研 (6D)：代表作、深度访谈口述实录、生死关键战役、生平转折跃迁、同行劲敌评价、失败与争议；
  • 心智操作系统萃取：3~7 个底层思维模型 + 5~10 条直觉决策启发式；
  • 原生表达指纹：独特的句式节奏、隐喻武器库与标志性反驳风格；
  • 三层保真度自检：已知历史战役回测、极端压力测试与风格盲测。
📚 仓颉体系 (Cangjie Skill) —— 铸造法典工具箱

“把书、长视频、播客等高价值内容蒸馏成可执行的 Agent Skills。”

  • R (精读解构)：剥离出版灌水案例，提取纯粹的方法论核；
  • I (逻辑重构)：因果机制推演链与概念拓扑图；
  • A (实战映射)：从虚构理论翻译为面向实战的祈使句和决策树；
  • TV (三重验证)：跨学科原理佐证、推演预测力、反常识决断锐度；
  • ++ (Agent 执行层)：标准化触发器、检查清单 (Checklists) 与验收军规。

💡 核心护城河：为什么这套机制绝对不会“卡死”？
  • 双轨自适应登台 (Dual-Track Staging Protocol)：主角登台后，总导演提供专属直达链接（通道 A）；若用户直接在主会话聊天框继续回复，总导演立即宣布舞台聚光灯直照当前包厢，主角无缝在当前会话直接登台破冰发话（通道 B），彻底杜绝跨窗口等待卡死！
  • 语义等价放行 (Semantic Equivalent Sign-off)：门禁不会死抠某 8 个字，凡用户回复“行”、“好”、“请开始”、“同意”，系统立即识别肯定意图并流畅放行，告别机械死锁。
  • 三级语料分级 (Stratified Ingestion L1~L3)：预置资产秒开，熟知名家 30~60 秒精准萃取，冷门资料才触发全网爬虫，规避搜索风暴与超时限流。
  • 贯穿式人设防线 (Voice-DNA Anchor)：强制第一人称叙事 + 章节名言引语 + 法典 Checklists 逐项核销 + 篇末手签印记，彻底杜绝 AI 公文腔。

05 一键安装与开戏实操指南（30 秒极速上手）

1 极速一键安装到全局技能库

解压 liangsheng-theater-v1.0-release.zip 后，根据操作系统运行对应安装程序：

🪟 Windows 用户（最简单）

直接鼠标双击运行 install.bat，脚本将全自动部署至全局环境并完成验证。

💻 PowerShell 用户
powershell -ExecutionPolicy Bypass -File .\install.ps1
🍎 macOS / Linux 用户
bash install.sh

* 全局安装目录：Windows: %USERPROFILE%\.gemini\config\skills\liangsheng-theater\ ｜ macOS/Linux: ~/.gemini/config/skills/liangsheng-theater/
